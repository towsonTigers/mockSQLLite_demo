What is?
 Drizzle - a TypeScript-first ORM where you define tables as JS/TS objects and query them with a typed builder (db.select().from(tasks).where(eq(...))) instead of raw SQL strings.
 
 Faker - a library for generating realistic fake data (names, sentences, companies) rather than a database tool.
 
 Knex - a SQL query builder (not a full ORM) with a fluent API (db('tasks').where({status: 'done'})) that works across many database backends. In your example it points at the same better-sqlite3 engine and same schema.sql, proving you can swap query layers without touching the schema.
